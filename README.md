Task Flow — Team Task Manager

Developed a full-stack web application to manage projects, assign tasks, and track team progress with role-based access control (Admin/Member). Implemented secure JWT-based authentication and designed RESTful APIs for project, task, and user management.

Built using React (Vite), Node.js, Express, and PostgreSQL (Prisma ORM), ensuring scalable architecture and efficient data handling. Deployed on Railway with automated database migrations.

Key Features:-
• Role-based access control (Admin/Member)
• Task assignment with status tracking (To Do → In Progress → Done)
• Project and team management system
• Dashboard for task insights and overdue tracking
• Secure authentication using JWT and bcrypt

Tech Stack:-

Frontend: React, TypeScript, Vite  
Backend: Node.js, Express, TypeScript  
Database: PostgreSQL (Prisma ORM)  
Deployment: Railway  

Highlights:-
• Designed scalable REST APIs with validation (Zod)
• Implemented secure password hashing and token-based authentication
• Built modular backend architecture (middleware, services, routes)
• Enabled full-stack deployment with database integration
